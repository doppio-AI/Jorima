# Jorima

Plataforma de bienestar laboral desarrollada con arquitectura fullstack basada en Next.js.

## Estructura

- web → Aplicación Next.js (Frontend + Backend API)
- movil → Aplicación móvil (React Native / Expo)

## Stack
- Next.js
- PostgreSQL
- JWT Authentication
- n8n (Workflows e IA)
- Render (Deploy)
